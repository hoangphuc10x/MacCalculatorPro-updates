# MacCalculatorPro updates

Update feed for MacCalculatorPro, a macOS calculator. The app's Sparkle updater reads
`appcast.xml` from GitHub Pages:

https://hoangphuc10x.github.io/MacCalculatorPro-updates/appcast.xml

Each update's `.zip` (for Sparkle) and `.dmg` (for first installs) are attached to this
repository's GitHub Releases. Every archive is EdDSA-signed; the app rejects anything else.

Do not rename this repository or move `appcast.xml`: installed copies of the app only
look at the URL above.
